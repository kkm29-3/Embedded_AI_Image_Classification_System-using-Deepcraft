# Embedded_AI_Image_Classification_System-using-Deepcraft
Overview:
This repository provides a code example for deploying computer vision machine learning models on Infineon's PSoC™ Edge MCUs using DEEPCRAFT™ Studio and ModusToolbox™. It demonstrates end-to-end Edge AI workflow, including model training, conversion, and inference for vision-based object detection with YOLO models.
